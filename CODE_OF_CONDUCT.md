# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep
criticism about the work, not the person. Harassment of any kind isn't
tolerated.

Report unacceptable behaviour privately to the maintainer through
[GitHub's report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or by opening a
[private security advisory](https://github.com/shamsu07/peel/security/advisories/new)
marked "Conduct". Reports are handled confidentially.
