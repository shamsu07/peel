# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/shamsu07/peel/security/advisories/new).

Include what you found, how to reproduce it and the app version
(Settings → About). You'll get a reply within a week.

## Supported versions

Only the latest release on the App Store, Google Play or GitHub Releases
gets fixes.

## Scope

Peel has no servers or accounts. The parts most worth looking at are the
Android sticker ContentProvider, file handling of picked media, and the
native libwebp code.
